# Too Yumm! / RP-Sanjiv Goenka Group AI Quality CRM 2.0

An AI-powered Customer Complaint, Plant Investigation & Corporate Quality Assurance (CQMS) portal modernizing the Too Yumm! CRM platform.

## 🚀 Key Features

- **Authentic 7-Chart Analytics Dashboard**: Real-time KPI counters (`Closed: 244`, `WIP: 695`, `Total: 939`), date range pickers, plant filtering, dynamic CSV report export, and 7 interactive pie charts (*Customer Connected For, Product Category, Product Wise, Response Action Status, Region Wise, Response Nature, Plant Wise*).
- **AI Packet OCR & Defect Vision Inspector**: Computer vision scan extracting batch codes, manufacturing dates, and packaging defect signatures (sealing leaks, pyrolyzed charring, underfill tare).
- **Multilingual AI Voice Note Transcriber**: Live audio speech-to-text supporting English and Hindi/Hinglish WhatsApp voice notes with automated form population.
- **AI Fraud & Voucher Abuse Radar**: Perceptual image hashing and claim velocity verification to prevent duplicate voucher claims.
- **Breakdown Log Sheet**: Manufacturing plant equipment breakdown logger with downtime tracking, MTTR analytics, and AI predictive maintenance diagnostics.
- **Internal Complaints (Factory Holds)**: In-process quality hold management tracking quarantined kg and disposition decisions (*Scrap Quarantine, Rework, Lab Testing*).
- **Masters Configuration Console**: Full management interface across all 10 master tables (*Region, Complaint Source, Product Category, Product Name, Product Flavour, Plant Name, Response, Complaint Category, Complaint Sub Category, Complaint Status*).
- **Automated 8D CAPA & 5-Why Engine**: Complete D1-D8 engineering root cause synthesis linking line telemetry to corrective SOPs.
- **AI Outbreak Radar & Statutory FSSAI Notice Generator**: Multi-city batch contamination detection and automated Form G food recall notice generation compliant with FSSAI regulations.
- **Too Yumm! Quality Intelligence Copilot**: Conversational AI assistant for instant batch inquiries and customer apology generation.

## 🛠️ Tech Stack

- **Frontend**: React 18 (TypeScript), Vite 5
- **Styling**: Modern Vanilla CSS, CSS3 Custom Properties, Glassmorphism, Google Fonts (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`)
- **Icons**: Lucide React
- **Data Visualization**: Native Responsive SVG Charts with trigonometric arc calculations
- **Export Engine**: Client-side RFC 4180-compliant CSV generator

## 📦 Getting Started

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
```
